## GitHub Release 文案 · v1.0.0

第一个正式版本 🎉

**Video English Coach** 把英文视频和字幕变成互动学习课。

### 新增
- 从 SRT/VTT/ASS/TXT 字幕提取语境词汇与高频表达
- 生成可搜索、可打印的 CSV + 离线 HTML 词表
- 离线主动回忆练习页，支持 1/3/7/14/30 天间隔复习
- 浏览器本地进度保存与导入导出
- 通用 Skill 定义，可被任意 AI Agent 调用
- 零第三方依赖，Python 3.9+ 即可运行

### 说明
- 无云端同步，复习进度保存在浏览器本地
- 无字幕时需自行提供字幕或使用外部转写工具
- 不发送后台提醒

完整文档见 README。欢迎反馈与 Star ⭐
