它能做什么

不是一个背单词 App，而是一套把视频变成学习材料的工具链。

🎯

语境抽词

从字幕中提取真正用得上的词汇和表达，而非一味挑生僻词。

🧠

主动回忆

靠"不提示想起"来记忆，而不是反复看答案的自我安慰。

📅

间隔复习

内置 1 / 3 / 7 / 14 / 30 天复习安排，进度保存在本地。

💬

AI 陪练

配合 AI Agent 完成听力理解、跟读、复述与纠错。

📄

离线导出

可搜索、可打印的 CSV 词表与独立 HTML 页面。

🪶

零依赖

Python 3.9+ 标准库即可运行，无需第三方包与 API Key。

快速开始

零依赖，克隆即可运行。

git clone https://github.com/grocksdf/video-english-coach.git
cd video-english-coach
python scripts/cli.py run assets/sample_subtitle.srt -o ./my_study --level B2 --json

能力边界

实话实说，避免误解。

  • 不提供云端同步；复习进度仅保存在浏览器本地
  • 不自动转写所有视频；无字幕时需你提供字幕或使用外部转写工具
  • 不后台推送复习提醒；它不会主动发送消息
  • 不宣称能科学测量"发音分数"或"掌握率"
